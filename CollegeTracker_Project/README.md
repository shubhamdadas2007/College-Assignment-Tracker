# 🎓 College Assignment & Practical Submission Tracker (v4.0)

A modern desktop application built using **Python 3**, **Tkinter**, **SQLite**, and **Matplotlib**.

---

## 🚀 How to Run

### Method 1: One-Click Launch (Windows)
Double-click **`run.bat`**. It will install required dependencies and launch the application.

### Method 2: Manual Terminal Run
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python main.py
   ```
